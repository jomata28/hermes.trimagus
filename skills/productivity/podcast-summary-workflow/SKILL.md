# Podcast Summary Workflow

## Trigger Conditions
- User requests summaries of podcasts (specifically Divine Intervention Pharmacology mentioned)
- User wants to study from podcast content
- User communicates via Telegram voice messages

## Steps
1. When user asks for podcast summary, acknowledge request
2. Use available tools to fetch/process podcast content (YouTube transcript, etc.)
3. Generate concise summary suitable for studying
4. Send summary to user via Telegram (their preferred communication method)
5. Confirm delivery with user

## Pitfalls
- Don't assume user knows which podcast - clarify if needed
- Don't send overly long summaries - user wants to study, not re-listen
- Remember user prefers Telegram voice messages but may accept text summaries
- User is in Houston, Texas (Central Time) - consider timing if scheduling

## Verification
- User confirms receipt of summary
- Summary captures key points for studying
- User doesn't need to ask again for same content
