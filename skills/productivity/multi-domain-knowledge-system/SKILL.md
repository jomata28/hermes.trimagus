# Multi-Domain Knowledge and Tracking System Setup

## For professionals with diverse interests (research, entrepreneurship, training, etc.)

### When to use this skill
When you need to organize knowledge, track projects, and build systems across multiple life domains (academic/professional work, side businesses, fitness/health, personal learning) and want them to work together synergistically.

### Core Components to Set Up

#### 1. Central Knowledge Hub (Choose one or integrate)
- **Obsidian Vault**: For networked, markdown-based notes with bidirectional linking
  - Best for: Deep thinking, connecting ideas, long-term knowledge retention
  - Setup: Create vault structure with folders/domains
    - `00-Inbox` (capture everything here first)
    - `01-Projects` (active endeavors with deadlines)
    - `02-Areas` (ongoing responsibilities: Research, Training, Business)
    - `03-Resources` (reference materials, literature notes)
    - `04-Archive` (completed/inactive items)
  - Use daily notes for journaling and capture
  - Use templates for different note types (meeting, idea, literature, workout)

- **Notion Workspace**: For databases, project tracking, and structured data
  - Best for: Project management, tracking structured data, collaboration
  - Setup: Create interconnected databases
    - `Ideas` (capture and evaluate entrepreneurial/research ideas)
    - `Projects` (active projects with timelines, tasks, status)
    - `Tasks` (action items with due dates, priorities)
    - `Knowledge Base` (structured reference information)
    - `Training Log` (workouts, progress, metrics)
    - `Meeting Notes` (with links to related projects/tasks)

#### 2. Capture System (Reduce Friction)
- **Voice Capture**: 
  - Telegram voice messages → transcribe → send to inbox
  - Mobile voice memos → auto-sync to processing system
- **Quick Capture**:
  - Notion mobile app for quick idea/project entry
  - Obsidian mobile app for quick notes
  - Browser extensions for saving web inspiration
- **Processing Inbox**:
  - Daily/weekly processing: Convert captures to proper notes/tasks/projects
  - Apply the "2-minute rule": If it takes <2 minutes, do it now

#### 3. Domain-Specific Systems

**For Research/Academic Work:**
- Literature notes: Use progressive summarization (highlight → bold → notes → summary)
- Project tracking: Experiments, hypotheses, results, next steps
- Meeting notes: Link to relevant papers/projects
- Conference notes: Capture insights and action items

**For Entrepreneurship/Side Projects:**
- Idea evaluation pipeline:
  1. Capture: Quick entry when idea strikes
  2. Evaluate: Use framework (ICE, weighted scoring, pre-mortem)
  3. Prioritize: Review backlog weekly, select 1-2 to test
  4. Test: Define smallest validatable experiment
  5. Track: Metrics, learnings, pivot/persevere decisions
- Project tracking: Milestones, resources, dependencies, outcomes

**For Training/Fitness:**
- Workout logging:
  - Strength: Exercise, sets, reps, weight, RPE
  - Cardio: Distance, time, pace, route, HR
  - Skills: Techniques practiced, drills, sparring notes
  - Recovery: Sleep, soreness, energy levels, nutrition
- Progress tracking:
  - Weekly: Volume trends, intensity, PRs
  - Monthly: Measurements, photos, performance tests
  - Quarterly: Program review, adjustments
- Knowledge integration:
  - Link workouts to fitness science notes
  - Track what you're learning about your body's responses
  - Build personal physiology knowledge base

#### 4. Connection and Synthesis Mechanisms
- **Weekly Review** (60-90 minutes):
  1. Process inbox
  2. Review project progress
  3. Update metrics and tracking
  4. Identify blocked items and next steps
  5. Review knowledge base for connections
  6. Set priorities for coming week
- **Monthly Reflection** (2-3 hours):
  1. Review goals and progress
  2. Analyze training/data trends
  3. Review idea pipeline and decisions
  4. Adjust systems and processes
  5. Archive completed projects
- **Automated Connection Finding** (optional):
  - Use LLM to analyze knowledge base for latent connections
  - Generate prompts: "How might X from domain A relate to Y in domain B?"
  - Create synthesis notes that integrate insights across domains

#### 5. Tool Integration and Automation
- **Cron Jobs/Scheduled Tasks**:
  - Weekly knowledge base backup
  - Automated report generation (training progress, idea pipeline stats)
  - Data exports for analysis
- **Sub-agent Workflows**:
  - Idea research assistant: Find relevant papers/market data
  - Meeting summarizer: Extract action items and decisions
  - Training analyst: Weekly progress report with suggestions
  - Content repurposer: Turn notes into social media/blog posts
- **API Integrations** (where useful):
  - Notion ↔ Obsidian (via exports or third-party sync)
  - Calendar → Time blocking for projects/training
  - GitHub → Track entrepreneurial/technical projects

#### 6. Getting Started (Progressive Implementation)
**Week 1: Capture Foundation**
- Set up quick capture (voice → processing system)
- Choose primary system (Obsidian or Notion as hub)
- Create inbox processing routine

**Week 2: Core Systems**
- Set up project tracking for 1-2 current endeavors
- Begin training log (even if simple)
- Create idea capture system

**Week 3: Integration**
- Link related items across domains
- Begin weekly review practice
- Set up first automated process (if desired)

**Week 4: Optimization**
- Refine based on what's working/not working
- Add depth to tracking where useful
- Plan next quarter's experiments and goals

### Key Principles
1. **Start Simple**: Begin with what gives immediate value
2. **Friction Reduction**: Make capture and logging as easy as possible
3. **Regular Review**: Systems decay without maintenance
4. **Emergent Value**: Connections and insights appear over time
5. **Personalization**: Adapt frameworks to your specific workflows
6. **Progressive Disclosure**: Simple views for daily use, detailed views for analysis

### Avoiding Common Pitfalls
- **Tool Obsession**: Focus on use, not perfect setup
- **Over-Complexity**: Start minimal, add only what solves real pain
- **Inconsistency**: Schedule processing time like any important appointment
- **Perfectionism**: "Good enough" notes that exist are better than perfect notes that don't
- **Isolation**: Regularly review how domains connect and inform each other

### Evaluation and Iteration
Ask monthly:
- What's saving me time/cognitive load?
- What's helping me make better decisions?
- What connections am I noticing that I wouldn't have seen otherwise?
- What's creating friction that needs to be simplified?
- What's one experiment I want to try next month?

This system should serve you - not the other way around. Start where you are, use what you have, and build gradually toward the integrated knowledge and tracking system that supports your multifaceted life and goals.
