# Dreamlining in Bitácora

Use this when JT wants to fill, archive, or operationalize a Dreamlining artifact/session.

## Placement

Dreamlining is a review/ignition layer, not a single pillar project. Store it under:

```text
5-Admin and Reviews/reviews/dreamlining/
```

Recommended files:

- `00-dreamlining-hub.md` — explains purpose, ONEPISSA mapping, and rules.
- `assets/<artifact>.html` — the interactive HTML artifact if provided.
- `<YYYY-MM-DD>-dreamlining-session.md` — the preserved fill session.

## Operating model

- PARA decides where outcomes live after the session.
- ONEPISSA classifies each dream by life pillar.
- Dreamlining captures raw desires in **Tener / Ser / Hacer** over 6- and 12-month horizons.
- Convert every **Ser** item into a concrete **Hacer** proof.
- For chosen 6-month dreams, define 3 steps plus actions for: now, tomorrow before 11 a.m., and the day after before 11 a.m.; each action should be ≤5 minutes.

## Conversation workflow

1. Create the session note first so answers are preserved.
2. Ask for messy fragments, not polished prose.
3. Fill 6-month **Tener / Ser / Hacer** first.
4. If JT says he already has items “from my own goals,” mine existing Bitácora pursuits/projects first and present candidates as reminders, not commands.
5. Then fill 12-month **Tener / Ser / Hacer**.
6. Select the strongest 1–3 six-month dreams.
7. Convert to steps/actions and map to ONEPISSA.
8. Patch the session note after each answer batch; do not wait until the end if the user is voice/text dumping over time.

## User-specific framing corrections

JT corrected the assistant during a Dreamlining session: **Hacer should be concrete proof-events, not broad categories.** Do not write final Hacer entries like “Texas-window items” or “language project.” Those can appear in candidate notes, but the final Hacer list should be an observable event or outcome.

Good Hacer examples from JT:

1. **Hold a 5-minute Italian conversation** with GF, made specific: no switching to Spanish/English; include greeting, daily update, one feeling/opinion, one question, and closing.
2. **Add a second income stream that at least doubles current income** by getting paying AI clients, likely through FoundationAtlas / AI receptionist / missed-lead recovery.
3. **Go to Big Bend** — solo version preferred if safe/logistically ready.

If a geographic or time-window constraint matters (e.g. leaving Texas), surface it as context, but do not let the constraint replace the concrete dream.
